# 资金脉冲：快照提示与手机密度

本批仅统一资金页面的排版和文案，不增加数据源、采集任务或权限。

- 页面沿用观澜黑橙与明暗主题，左右间距和异动接力一致，不再额外居中限制为1440px。
- 顶部依据归档阶段及实际完成时刻区分“收盘快照”“午盘快照”“盘中采样快照”，始终显示资料日期及非当前实时。盘中采样超出更新窗口仍标过期；收盘档案不再误写成持续滚动的实时数据。
- 主要区域只留“更新频率：交易时段计划每30分钟采样，非逐笔实时”。实际采集窗口、接收归档、关联行情时间、版本、连续性验收和资金估算口径，收进默认关闭的“采样详情与口径”。缺净额时仍在榜单前明确提示，缺失不计为0。
- 手机小图使用44px高的真实采样预览，隐藏不适合此高度的细小坐标；点开的大图保留完整坐标、金额、实际完成时间及原始表。列表金额保持14px和完整数值，名称列收紧，仅表格自身横滑，页面保持原生纵滚。
- 桌面迷你图与大图保持原样。所有图表保留零值、孤立点、漏采／缺值／午休断线，不平滑、补点或改写历史。

更新时间计划不保证每批成功；页面读取和切换不触发市场抓取，不自动重排。累计净额是来源按成交金额分桶的估算，不等于机构持仓或真实新增资金；相邻变化也不代表加速度。

验收和实际发布记录见根目录 CHANGELOG。当前是源码开发预览，不包含新的安装器。ECharts许可和NOTICE沿原页面入口提供。本地Agent、登录、个人资料、腾讯采集器与OpenClaw不在本批变更范围。
