# 战法研究 Beta

入口：侧栏一级菜单“战法研究 Beta（测试）”，位于“复盘”后、“个股档案”前；手机“更多”内研究工作区有独立入口，地址 `/next/strategy-lab`。不放在盯盘二级菜单中，也不高亮盯盘。本批为研究工具试验，不执行交易，也不改变个人策略或权限。

## 首版范围

- 高度龙头观察：在同一收盘成品内先计算最高连续板，再应用题材标签、连续板及数值条件；只是市场高度候选，不认证龙头。
- 换手连板观察：连续板、换手率、成交额与来源原因标签取交集。默认数值是可修改的 Beta 试验参数，未验证收益、胜率或适用性。
- 首次分歧后再转强、情绪核心／断板修复：目前只有规则模板，连续过程证据不足，不运行筛选、不填示例候选。
- “描述我的战法”只预填现有问观澜入口，用户明确发送后才调用原模型；不自动提交、重试或切换费用来源。

## 数据与时间

只读取既有 `/api/data/free?view=watch` 日期和受原权限保护的 `/api/v2/high-board?date=...` 收盘共享成品，不新增市场抓取、模型定时任务或全市场扫描。该成品最多展示40只连续2板及以上高标，首板不在候选范围；封板池覆盖与已读高标数量分开显示。有展示上限时明确提示，不以本页结果代表全市场。

规则先确认再应用，数据必须与选择的收盘日期一致。资料未就绪不改读其他日期；刷新失败保留同日期原成品与版本。候选、缺数据、不符合分开。没有同批题材标签或所需换手／成交额时列缺数据，不填0。

未提供ST、一字板、完整竞价、逐笔承接、情绪周期或完整板块支撑筛选，不能把用户描述中的这些要求视为已经执行。AI整理时应保留为待确认／待支持事项。

## 规则草稿

保留用户描述与独立的规则参数。AI结果须手动复制JSON到本页、校验导入、核对后再次确认；不执行AI生成的代码、表达式或外部链接。修改参数或原文会撤销当前确认并隐藏旧结果。

固定字段：`version:1`、`title`、`scope`、`minHeight`、`minTurnover`、`maxTurnover`、`minAmountYi`、`theme`、`needs`。

- `scope`：`highest`／`ladder`可筛；`divergence`／`repair`仅规则模板。
- 连续板为2至30的整数；换手率为0至100，成交额为0至10000亿元，未限制的数值用`null`。上下限不能反向。
- `needs`为待确认事项数组，非空不能运行；不能仅删除问题来声称证据已补齐。
- 未知字段、字符串数值、非法范围和任意公式均拒绝；最多8000字符。

原文最多160字，整理提示词不超过原有500字提问边界。当前草稿仅本页状态，不自动归档到账号；确认后可导出原文、规则、确认时间及已读成品版本，离开前请自行保留。导出包包含元数据，不是自动入库或自动回测。
