# 首屏与共享读取优化

适用批次：2026.11.18.4。源码预览、线上 SaaS 和本地静态发布分别验收；不改 Agent、腾讯采集器或 OpenClaw。

## 首次打开

HTML 提前发起一次 `/api/me` 账号状态读取，与主模块下载重叠；React 接管同一个回执，不另发一轮。回执只在当前页面内存短暂存在，不写 localStorage，不提前读取持仓、报告或其他个人资料。退出／换账号会取消并清理，15秒内未接管则丢弃；请求仍有20秒超时，失败不在交接层隐式重试。

构建时从实际产物生成当前路由入口的预加载映射，只准备当前页入口和自身样式。不要递归抢读整个依赖图或所有路由；本批候选测速曾发现这种做法产生竞争，已收窄。原有已发布静态块保留，避免已打开页面的延迟导入失效。

Harness 保留自己的会话过期事件和资料保存逻辑，不能直接整文件复制 SaaS 的 api.ts。

## 共享资金读取

独立的快照正文、类别验收状态和各时点归档并行读取。趋势固定版本正文验证后可在同一服务实例短时复用：最多2份、保守估算总预算4MB、最长5分钟；不缓存资格状态，撤下相邻变化资格仍立即影响下一次读取。仍显示真实日期、缺值和过期状态，不把归档变成实时行情。

## 条件观测分页

共享服务只缓存公开市场快照，不缓存用户、登录会话或权限。每次先核验原登录与资料权限。最新指针每次重读；64位固定版本模型才可复用，最长60秒、最多2份、保守估算总预算16MB，失败不缓存、并发固定加载去重且有界。

每个模型最多保留8组精简筛选索引，总估算预算1MB、最长60秒。仍先按原算法核对完整范围，再分页取行；不是先取20只再筛选。模型、条件或行业成员改变均独立核对，完整总数、排序、缺数据与不符合结果不变。超过预算直接正常计算，不扩大缓存。实例内存被回收后正常重新读取，不依赖缓存保证正确性。

固定版本已验证正文可能在60秒内继续复用；这不是实时读取外部删除状态的承诺。缓存不改变资料本身日期、原始版本和 HTTP 验证器，异常与未授权请求不会借缓存放行。

## 如何复核

- 前端：`npm test`、`npx tsc --noEmit`、`npm run build`，构建后在 frontend 运行 `node --test test/critical-build.check.mjs`。隔离目录构建可用 `CRITICAL_BUILD_DIR` 指定实际 next 目录。
- 首屏：全新浏览器上下文检查 `/api/me` 只有一次并与模块阶段重叠，分别记录页面主模块、DOM 和首条真实结果完成时刻；冷启动不要用响应夹具做测速。
- 数据：固定同一模型，逐项比较两阶段、技术组合、匹配／缺项／不符合及分页的完整 JSON；缓存命中后匿名与无效会话仍应拒绝，ETag 不变时保持304。
- 手机：分页继续20条追加，固定模型；44px触控、原页面纵滚和表格横滑不变，故障刷新保留原结果。

具体本批次数与线上版本见根 CHANGELOG。短时少量、同一网络出口的测试不是全网 SLA 或高并发容量结论；本批未实测实体手机／Safari，也不含真实用户资料写入或模型调用。现有 Browser 插件未提供，使用本机 Chrome／Playwright。
