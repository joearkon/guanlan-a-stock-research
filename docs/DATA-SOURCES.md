# 数据来源与资金口径

观澜把行情、题材、公开资金披露和公司证据整理成可阅读、可筛选的共享资料。本地 Harness 使用自己的观澜账号读取这些资料，再由自己选择的 AI Agent 组织研究。

这里的“资金来源”指资金数据的出处和统计口径，不是产品融资或收取用户资金。观澜不连接券商资产、不代管资金、不自动交易。

## 本地版怎样取得资料

公开来源 → 观澜共享数据服务校验、缓存与发布 → 本地工作台读取；明确发起研究后，选定公开资料交给自己的 Agent。Agent 经允许自行联网补充的内容，应与观澜快照分别标明出处和日期。

用户需要观澜账号及相应资料权限，不需要在当前本地版额外填 Tushare、东财或新浪密钥。Tushare 等上游凭据属于数据服务端配置，不随本仓库发布；本地版暂不提供自选任意行情源或一键接入自己的 Tushare Token 的功能。

低位转强结构筛选复用TuShare按交易日共享缓存的原始日线与复权因子，结合官方交易日历；至少60个连续已完成交易日并与同日收盘价匹配才计算。后台统一准备，Harness不另扫全市场、不依赖自己的Agent；新股、停牌缺档或复权缺项不补0。规则、时间与首次收录边界见[结构筛选说明](STRUCTURE-SCREENING.md)，它不是盘中信号或买入建议。

不是所有页面资料都会自动进入每轮 AI 输入。本轮实际附带的资料与 Agent 自行检索结果，分别以证据记录和回答中的来源为准。

以下为现有共享服务中的来源分工，整理日期为 **2026-11-16（北京时间）**。接入存在不等于每批均可用；权限、源站限制、发布时间及覆盖情况可能导致缺项或旧缓存。

| --- | --- | --- |
| 股票、指数报价 | [腾讯行情](https://gu.qq.com/) | 共享报价快照、价格、涨跌幅、成交额、换手等。报价时间与工作台打开时间分开；不是交易所逐笔行情承诺 |
| K线与复权 | 腾讯历史行情；部分个股研究场景由[同花顺](https://stockpage.10jqka.com.cn/)补充 | 分时、日／周／月及复权图表按实际接口支持提供。主图与个股研究补充不是同一条兜底链，不保证所有周期和标的都有补充源 |
| 涨跌停、炸板与昨日梯队 | [东方财富涨停板](https://data.eastmoney.com/ztb/detail)；同花顺强势股资料补充 | 涨跌停池、炸板、昨日涨停表现与原因标签。结合已保存价格与历史档案计算梯队，原因标签不等于已证明的涨跌归因 |

| 概念目录与成分 | [Tushare](https://tushare.pro/document/2)的同花顺／东财目录与成员接口、东财公开目录和关联、新浪概念目录及成员 | 保留提供方、板块代码、成员覆盖和采集时间；同名不直接合并，无历史生效日的当前分类不倒填历史 |
| 板块资金流向 | [东财资金流](https://data.eastmoney.com/bkzj/)、[Tushare moneyflow_ind_dc](https://tushare.pro/document/2?doc_id=344)；新浪板块资金补充 | 行业／概念资金观察及滚动窗口。Tushare 此接口提供的是东财口径，不是第二份独立机构证据；新浪单独标源 |
| 个股资金流向 | [Tushare moneyflow_dc](https://tushare.pro/document/2?doc_id=349)、东财公开资金读数、新浪个股资金序列 | 用于资金结构与个股研究。东财主力与新浪特大单的定义不同，不能混加、横比绝对值或据此确认买方身份 |
| 龙虎榜与机构席位 | [东方财富公开龙虎榜](https://data.eastmoney.com/stock/tradedetail.html)，基于公开交易披露 | 机构买方出现、净额、最近披露与逐日依据。当前足迹读取已有东财席位档案，不将 Tushare 的同类接口宣传为另一条已启用足迹源 |
| 估值、指数与两融 | Tushare `daily_basic`、`index_daily`、`index_dailybasic`、[margin](https://tushare.pro/document/2?doc_id=58)等 | 估值历史、指数历史、部分风险与融资融券背景。指数成交额和全市场成交额按各自来源口径理解，不混接成一条序列 |
| 公告与公司基础资料 | [巨潮资讯](https://www.cninfo.com.cn/)、交易所／上市公司披露；东财公告镜像；Tushare `anns_d`、`stock_company`等 | 公告索引、原文入口及主营资料。索引、标题与已读取正文分开，事实以对应公司原始披露为准 |
| 财务报表与主营构成 | [新浪财经](https://finance.sina.com.cn/)财务报表、东财主营构成；Tushare `fina_mainbz`等补充 | 利润表、资产负债表、现金流与业务收入拆分。保留报告期、单位、原始来源；没有可靠单位或同口径历史时不补造比率 |
| 新闻、事件与宏观日历 | [财联社](https://www.cls.cn/)、东财新闻和事件数据、[华尔街见闻](https://wallstreetcn.com/)宏观日历 | 新闻线索、原始事件与经济日历。报道不自动等于公司公告，也不证明市场已经按该事件定价 |
| 产业与研报 | [东财公开研报](https://data.eastmoney.com/report/)、券商报告原文、公司官网／定期报告、行业组织公开资料 | 产业链、业务传导、公司案例和已发布研究。报告目录不是全文，券商判断不是公司已实现业绩，注册公司名单不是全部尽调完成 |
| 交易状态 | [深交所](https://www.szse.cn/)官方交易日历 | 核对开休市，结合北京时间显示盘前、竞价、盘中、午休与收盘等状态；日历缺覆盖时待核验，不把状态当成行情实时性的证明 |

部分席位的俗称关联来自证券时报、界面新闻等公开历史报道，只作为有来源的历史关联标签，不确认本次交易者身份。

## 资金读数分别代表什么

| 页面或读数 | 表达什么 | 不能据此认定什么 |
| --- | --- | --- |
| 主力净流入／净流出 | 对应提供方按成交或订单分类统计的资金读数；先核对来源、单位和期间 | 不等于全部机构净买入、真实持仓变化或账户级资金进出 |
| 新浪特大单净额 | 新浪自身的特大单统计序列 | 不与东财“主力”互称或相加；更换源后不能直接称为资金改善或反转 |
| 龙虎榜机构净额 | 已披露机构席位买卖金额差，受上榜范围和披露规则限制 | 不是全市场机构资金，不代表所有基金或机构的实时持仓 |
| 近5／10日机构净额：单日榜 | 窗口内按单日披露去重后汇总；完整性以档案覆盖为准 | 不是只看最新一天，也不能在缺档时把已收录金额称为完整窗口总额 |
| 累计榜披露 | 读取累计榜对应区间与最新披露；保留原区间身份 | 不能把重叠多日区间再逐条累加，不能与单日榜混算 |
| 最近机构披露／机构净额 | 最近一次有对应机构披露的日期和金额，可能与行情日不同 | 不等于今天的机构净买入，也不等于近5／10日总额 |
| 两融余额 | 对应交易日、对应交易所的融资融券余额；观澜相关汇总保留实际覆盖范围 | 余额不是当日净流入，不代表全部杠杆资金；不能默认包含未覆盖市场 |
| 板块资金合计 | 某一分类或其已核验成员范围内的资金统计 | 概念成员重叠，不能把多个概念简单相加当成全市场资金规模 |

Tushare 文档中，`moneyflow_dc.net_amount` 原单位为**万元**，`moneyflow_ind_dc.net_amount` 原单位为**元**；观澜展示按对应字段转换，不能因为同名就假设单位相同。详情见上述两份官方接口文档。

“机构参与后分歧”等预设是基于披露与价量条件的观察规则，不是对真实机构持仓、后续走势或收益的保证。没有上榜记录也不意味着没有机构参与。

## 怎样判断资料是否适合这次研究

先看资料日，再看采集时间、覆盖情况和来源身份。例如报价已更新，龙虎榜可能尚未披露；财报仍属于最近一个报告期。这不是三者日期必须一致的异常。

- **盘中与盘后：** 默认口径和显式切换后的共享快照分开，不把盘后成品写成当前实时行情。
- **历史与当前：** 读旧档不触发全市场重抓取；保留旧资料时继续显示旧日期与状态。
- **失败与空值：** 失败、缺档、尚未发布和确认为零是不同状态；缺项不补零，不让 AI 用常识填出数值。
- **分类与覆盖：** 目录、成员、价格和资金可能来自不同时间；只在身份、日期与覆盖可核验的范围内汇总。
- **来源与推断：** 平台统计、券商观点和 Agent 推断分别理解；需要做决策时回到原始证据核验。

## AI 与数据的费用来自哪里

| 环节 | 来源与边界 |
| --- | --- |
| 读取观澜共享资料 | 沿用自己的观澜账号权限、权益和限流，不借用用户本机 Tushare Token。会员或试运营政策以官网为准 |
| Codex | 使用自己已登录的 Codex 账号及实际认证对应额度 |
| WorkBuddy／CodeBuddy | 使用自己已登录的供方账号额度 |
| Claude Code | 使用自己官方登录或实际配置对应的额度；订阅、API或其他认证费用来源需核对，不能只凭安装成功判断 |
| DeepSeek | 使用自己配置的官方 API Key 与 API 余额，不是网页聊天额度；实际联网工具等费用按供方规则 |
| 连接测试与研究 | 环境检测不调用模型；主动连接测试、明确提交研究可能消耗所选供方额度。失败不自动重跑或切换其他计费来源 |

“本地”指工作台、连接、调度与个人记录在本机，不保证模型完全离线。明确交给 Agent 的问题和公开证据可能发送给所选供方；不自动发送持仓成本或登录文件。供方未提供的 Token、内部调用数、剩余额度不补零。

## 哪些不应当宣传为已接入

- **AkShare：** 是数据接口工具与参考实现，不是另一家原始行情提供方。部分接口契约参考了其公开实现，不等于本仓库已内置或需要安装 AkShare。
- **通达信／mootdx、百度等：** 不因其他 Skill 或方案支持就列为当前 Harness 已启用的常驻数据源；当前本地版没有让用户配置它们的完整采集管道。
- **券商账户、交易所付费逐笔／Level-2：** 不在当前本地版已交付能力中。
- **Agent 自行找到的网站：** 属于该次研究的新证据，不自动成为观澜固定接入源。

来源介绍不代表与供方建立合作、获得背书或取得数据再分发许可。源码许可不覆盖第三方数据、研报全文和商业 API 权益；机构或对外商用还需核对各数据提供方的使用条件。
