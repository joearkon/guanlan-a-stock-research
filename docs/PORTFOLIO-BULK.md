# 自选与持仓批量管理

2026.11.26.2，沿用“我的股票 → 自选与持仓”，不新增菜单或账户库。

## 使用

进入自选或持仓，点击“批量管理”，逐项勾选或全选当前筛选结果，再点“移除所选”。确认抽屉列出名称、代码和类型，取消不保存；再次确认后以原版本一次保存整批。进入批量模式后点行也能勾选，不打开行情或编辑，不允许拖动排序。退出模式恢复原交互。

“全选”只指当前类型／分组筛选下的可见集合，不包含其他分组或归档。股票与ETF等同代码对象按类型和代码区分。切换类型、分组、账户或自选／持仓页面会重置批量选择。

## 数据边界

- 自选：原记录标记归档，关注原因、加入基准、研究信息保留，不改持仓。
- 持仓：只移除观澜中的持仓记录，不代表卖出、不生成实际成交，不改自选。
- 提醒和正式研究档案均不随批量移除删除。
- 成功后当前页面提供“撤销本次批量移除”，恢复本批原记录与顺序。账户随后已发生其他修改时拒绝撤销覆盖，需要重新读取核对；开始新一批管理、切换筛选／账号／页面或关闭页面后不保留原撤销入口。
- 保存前和服务器均校验原账户版本。失败／冲突／超时不自动重复提交，也不声称服务器一定未写入；保留已读列表，必须显式重新读取账户核对后重新选择。
- 隐私模式开启时禁用批量编辑，不在确认清单中暴露股数或成本。
