# 资金脉冲：功能预览

桌面从「盯盘 → 资金脉冲」进入；手机从「更多 → 首页与盯盘 → 资金脉冲」进入，底部仍归盯盘。SaaS与Local Harness同步页面，Local Harness不另外采集市场。

## 四个视图

| 视图 | 预期用途 | 当前边界 |
| --- | --- | --- |
| 当日排行 | 行业、概念或个股的同日主力净额流入／流出前10 | 数据验证中，不展示候选数值 |
| 资金脉冲 | 相邻有效采样净额变化，不是当日累计 | 缺少有效基准时不计算，不跨午休或缺口补0 |
| 近5日台账 | 前5个完整交易日的上榜天数与净额 | 不包含未完成的今天，不补造缺失历史 |
| 时点快照 | 午盘、下午、收盘就绪各留一份原时点档案 | 验收前标为待验收，不用当前滚动数据倒填 |

计划按交易日每30分钟共享采集，午盘11:30、下午14:30、收盘就绪15:05另存。均为北京时间，实际采集窗口和完成时间以回执为准，不保证该分钟已经就绪。

主力净额是来源按成交金额分桶估算的净买入额，不代表机构持仓或真实新增资金。拟用东方财富行业、概念与个股资料；行业与概念成分可能重叠，金额不能相加。关联行情时间也不是所有资金字段的独立时间。缺少同源近5日价格依据时不生成高低切标签，标签只作观察。

## 当前状态

2026.11.17.3只开放功能预览和口径说明。预览模式不调用未发布的资金API，也不显示旧查询缓存中的金额。切换范围或页签不会重复抓取市场，不调用任何AI模型。原复盘资金观测与本地Agent连接逻辑不变。

共享采集器已隔离安装，签名回传和盘前运行通过；这不等于真实盘中源已验收。后续仍需核验官方交易时段的完整目录覆盖、不同分钟的真实资金变化、自动定时执行和三个时点原始档案，再另行开放数值读取。功能不会因为时间到了而自动取消验收门槛。

## 本批验证

本地前端124项、服务55项，SaaS前端873项，TypeScript与构建通过。两端320、390、1440像素及明暗模式，候选与正式各12组页面验证通过；范围和四个页签可用，手机更多入口与底部盯盘高亮正确，无页面横向溢出或嵌套纵向滚动。真实个人资料写入和模型调用为0，测试会话已撤销。浏览器模拟不是实体手机实测，也不是盘中数据验收。
