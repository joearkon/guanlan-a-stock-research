## 产品流程

战法研究确认读取 → 勾选已匹配候选 → 生成次日观察单 → 可选主动打开问观澜并发送 → AI判断与反证回填为待核对草稿 → 人工填写触发／取消条件并确认 → 保存到账号作战看板。

每条保留战法、数据日期及完整模型版本、价量快照事实、资料缺口、AI支持与反证、待确认假设、人工触发与取消条件、仅次一交易日有效的观察日期、新买最早可卖日期、创建时间、原AI任务编号、用户后续核对状态。日历不足不猜日期；普通A股新买T+1与旧仓可卖量分开。价格和成交量不认证资金净流入，AI结果不改正式筛选规则。

首版触发／取消为人工文字计划，不自动判断、不推送提醒、不记录成交或改自选持仓。AI需显式发送，打开页面、生成草稿、刷新、保存与看板读取都不调用模型；每批只核对原任务，超时不新建任务。AI关闭后仍可按原编号读取结果；未提交的草稿关闭可重新打开，已提交不重复创建。

## 账号同步与边界

- 新端点仅 `/api/research/observation-plans` 的GET／PUT，不扩展其他Harness私有接口。
- PUT须明确同步同意、同源Origin、X-GL、绑定读取时的accountId与集合version。其他账号、旧版本、过大内容、未知字段、伪成交状态、提前核对均拒绝；已确认事实、AI及条件不可原地改写，只能新建观察单。
- 独立 `strategy_observation_plans` 表，最多20条／账号，UTF-8请求最多200KB，不修改原profile、研究历史或权限。保存回执未知时锁住重提，先重新读取核对，避免重复保存。
- 用户勾选“仅这批模拟观察单随账号同步”后才上传计划。其他本地报告、持仓、自选、引擎配置和密钥不会随计划上传。Harness本机AI不回退平台AI；SaaS沿原额度和模型权限。
- 看板可“读取账号更新”，这是只读操作；不是跨设备实时推送承诺。删除需再次明确确认且仅删除观察单；提醒、AI原始回执与交易记录不随之删除。
- 观察单草稿保留在当前页面，只有确认保存后才是账号记录；不是无确认的自动存档。
