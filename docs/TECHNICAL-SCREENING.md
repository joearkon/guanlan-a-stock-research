# 均线与MACD条件筛选

入口：复盘 → 条件观测 → 价量筛选 → 调整筛选条件 → 更多条件 → 技术指标。

可同时选择股价高于5／10／20日均线、当日上穿、MA5向上、多头排列、MACD金叉、DIF上穿零轴和红柱增强，并叠加价量、市场和行业条件。多选为同时满足，点击应用才筛选，原方案保存方式不变。

第一版使用已经完成的收盘日线，MACD参数12/26/9，前复权且跨日统一基准。上穿是“前日不高于、当日高于”，不是仅在均线上方；红柱增强包含当日翻红。显示指标日及前一交易日；历史不足、前日缺档、因子未收录或同日价格不一致时单列缺数据，不补0或借用其他日期。

共享后台计划在北京时间19:30后尝试更新当日因子，具体按实际收录日期显示，不保证供方此时已更新。盘中不能应用这组技术条件；可取消技术条件后沿用原盘中价量筛选。

数据来自观澜共享服务的TuShare技术因子，使用自己的观澜账号读取；本地不会逐股拉K线、保存TuShare凭据或调用模型。本批不改变本地AI Agent、登录、持仓、自选或研究报告。时间点、方案与分页继续沿已有同版本规则，手机不增加结果区纵向滚动层。
